# Greamworks v232.106

## Artifact

`Greamworks_v232.106_Processing_Loot_CreativeTabs.mrpack`

## Changes

- Vanilla mob spawners now use a 20-block activation range.
- The 23 registered fluid-stone reactions now have matching Create mechanical-mixer recipes visible in EMI.
- Chemica, Silent Gear, and TFMG ores gain chance-based Create crushing routes.
- Create millstone processing is expanded for modded stones and industrial byproducts.
- Apothic Enchanting gains new Eterna, Quanta, and Arcana infusion routes.
- A hidden-items creative tab is added; Omni-Alloy and the guide book are in Greamworks, and Void Shard is in Cataclysm.
- Global chest loot gains low-tier food, tools, Andesite Alloy, Stick n Stone equipment, and Silent Gear templates.
- Stick n Stone wooden weapons have 20 durability.

Create: Easy Stone Generators is intentionally not included.
